# CS 341 Books — Reader Feedback

Help improve *Algorithms: Reference Notes* and *Algorithms: Workbook* for
CS 341 at the University of Waterloo. Corrections, reports of confusing
explanations, and suggestions of any size are welcome.

[Read the books](https://eblais.github.io/cs341-books/) ·
[Browse existing feedback](https://github.com/eblais/cs341-books-feedback/issues)

| What would you like to share? | Use this form |
| --- | --- |
| A typo, incorrect equation, broken link, or mistake in an algorithm, proof, hint, or solution | [Report an error](https://github.com/eblais/cs341-books-feedback/issues/new?template=01-error.yml) |
| A passage, notation, or problem statement that is hard to understand | [Flag an unclear explanation](https://github.com/eblais/cs341-books-feedback/issues/new?template=02-clarity.yml) |
| A new example or exercise, a change to the organization, or another local or global improvement | [Suggest an improvement](https://github.com/eblais/cs341-books-feedback/issues/new?template=03-suggestion.yml) |

You do not need to know the correction to report an error or confusing passage.
A short description is enough, and it is fine to say that you are unsure.

Please identify the book and the relevant chapter, section, theorem, or exercise.
A short quotation and page number help us find the passage even after the books
change. For broader feedback, enter “whole book.” If you know the PDF's version
or date, please include it; otherwise, leave that field blank.

If you find an existing issue about the same topic, add your observations there.
Otherwise, open a new issue, preferably one per independent concern.

Reports and comments here are public. Use your usual private course channel for
assignment submissions, grading questions, or personal information. You need a
GitHub account to post here; if you prefer not to use GitHub, contact a course
instructor through your usual course channel.

This repository collects feedback. The book sources and editorial pull requests
are maintained separately. An open issue marked `awaiting-publication` has a
correction in the source that has not yet appeared in the public PDF. When a
correction is published, we will reply with the outcome and close the issue.
